01

背景与目标

1.1 素材证据

另有 5 张风格参考图 raw/01~05，各自带有技法说明卡（STYLE 01–05 / 05），是本页“五风格切换”的画面与切换器 UI 的直接依据，规格见 FR-05。

1.2 创意推导

事实 → 产品反应 程序员的共同图腾是键盘；品牌已有实体键盘与三维键帽视觉资产；1024 活动窗口为 10.19–10.24 事实
→ 把活动首页做成一次“敲出 TRAE1024”的仪式：无访客操作时自动上演，键盘爱好者可用自己的物理键盘“接力”敲入；
→ 五种实时画风让同一个三维镜头可反复把玩，直接呼应目标受众（开发者）对图形技术的审美兴趣 产品判断

1.3 目标（可观察的行为结果）

  • 访客无需任何点击即可在首屏看完整场演出，并能复述叙事：键盘依次敲下 T R A E 1 0 2 4 → 汇聚成三维 TRAE1024。
  • 访客在成型态能用一次点击/一次按键在 5 种风格间切换，并看到同一场景被对应画风重绘。
  • “下载 TRAE”与“官方中文社区”两个出口在成型态常驻可见，一次点击即可在新窗口前往。
  • 不支持 WebGL 的环境仍能看到成型态主视觉与两个出口，不出现白屏或卡死。

不设量化流量/转化目标，不杜撰埋点指标；如市场部需要数据回收，另补埋点表（见第 7 节）。

产品契约

主要用户程序员 / 开发者：TRAE 现有用户与潜在用户，在 1024 活动窗口（10.19–10.24）通过社群分享、官网入口或外部链接访问，设备以桌面为主、移动端占比不可忽视 假设·待确认

完成证据访客看到三维 TRAE1024 成品态（HERO）；页面同时呈现两个转化出口；访客发生过至少一次风格切换（非强制，仅作为体验目标）

05

功能需求

每条需求按「触发 → 处理规则 → 结果与状态变化 → 异常与边界」描述。

FR-01加载与自动开场P0
触发
访客在任意受支持浏览器打开页面链接。
处理规则
  • 进入即显示 LOADING：近黑底 + 品牌绿点状粒子（呼应官网点阵），中央 TRAE 字标与等宽字体阶段文案，例如 // loading scene → // compiling 5 styles → // ready；文案随真实加载阶段变化，不使用假进度条。
  • 资源具备首帧渲染条件后自动进入 OPENING，不设置“点击进入”门槛。
  • 五个风格所需资源并行加载；首个默认风格资源就绪即可开场，其余风格在 TYPING 期间继续后台加载。
结果/状态
LOADING → OPENING；加载期间页面无白屏、无滚动跳动。
异常/边界
  • 默认风格资源失败：在 LOADING 内提供“重试”；两次失败后进入 FATAL FALLBACK（FR-07）。
  • 其余风格资源失败：仅该风格在切换器中置灰标注“暂不可用”，不阻断开场与其他风格。
  • 标签页在加载期间被切到后台：加载可继续；计时类演出在页面恢复可见前不起播（见 6.3）。
FR-02TRAE 键盘三维场景P0
触发
OPENING 阶段自动呈现。
处理规则
  • 场景主体为 75% 配列机械键盘：深色金属机身、深灰键帽、右上角旋钮、品牌绿 Enter 键、一枚紫色个性键帽，造型与配列以 raw/TRAE-Keyboard.jpg 为准 事实。
  • 场景色底为近黑空间 + 绿色点状粒子；可包含代码雨、线框立方体等装饰元素，密度不得遮挡键位识别（参考 banner）。
  • 八枚主角键帽（T/R/A/E/1/0/2/4）在 OPENING 末进入轻微呼吸态，预告敲击顺序；键面字符清晰可辨。
  • 桌面端为横向电影构图（键盘占画面中下区域）；移动端重构图为更近的竖向画面，主角键位始终在安全区内完整可见。
  • 品牌绿、TRAE 字标等品牌元素与官网视觉一致；精确色值与材质参数由视觉稿锁定 TBD。
结果/状态
OPENING 持续约 2.5s 假设·待确认，镜头缓推（dolly-in）至键位区后自动进入 TYPING。
异常/边界

访客在此阶段按 T 或点击 T 键：立即进入 TYPING 并敲下首键（见 FR-03）；按其他序列键仅给该键微弱下沉反馈，不提前启动；按风格控件可直接切换画风，不打断计时。

FR-03八键逐键敲击演出P0
触发
① 自动：进入 TYPING 后按固定节奏依次触发；
② 接力：访客按下物理键盘的当前目标键，或在触屏点击当前呼吸键，立即触发该键并跳过该键的自动等待。
处理规则
  • 顺序固定：T → R → A → E → 1 → 0 → 2 → 4，不存在错误分支，品牌仪式不被“按错”打断 产品判断：保证仪式完整性与零挫败。
  • 每键反馈四件套：键帽下沉并机械回弹、轴体背光脉冲（七绿一紫，见 4.3）、按键音效（FR-06）、键面字符增亮并在之后保持常亮。
  • 自动节奏：每键间隔约 0.8s 并带轻微随机（约 0.72–0.9s）模拟人手 假设·待确认；E 与 1 之间额外停顿约 0.3s；整段约 7s。
  • 输入处理：
    • 按下/点按当前目标键 → 立即敲下并推进到下一键；
    • 按下序列中的其他键（未来键）→ 该键微弱下沉提示，不推进、不判错、不发出完整敲击音；
    • 按下无关按键 → 忽略，不给视觉反馈；
    • 触屏只响应八枚主角键帽，规则同上。
  • 镜头随击键轻微摇移跟焦（T–E 一组、数字键一组），风格切换不中断、不重置序列。
结果/状态
键帽三态：默认（暗）／当前目标（呼吸引导）／已击（常亮，2 为紫色）。第 8 键“4”敲下后保持一拍 → 进入 ASSEMBLING。
异常/边界
  • 访客在 TYPING 中按 R：回到 OPENING 重新演出（重置全部键帽状态）。
  • 访客持续快速乱按：不产生报错或状态错乱；只有当前目标键的一次有效按下被接受，其余按规则忽略。
  • 后台切页：自动计时暂停，回前台后从被暂停的当前键继续（不重播已完成部分）。
FR-04三维成型与 HERO 成品态P0
触发
第 8 键敲下一拍后自动进入 ASSEMBLING；动画结束进入常驻 HERO。
处理规则
  • ASSEMBLING（约 2.5s） 假设·待确认：八枚键帽从键盘拔离升起、飞行，在键盘上方空间排列为三维 “TRAE1024”；绿色/紫色光效与粒子向字形收束；实体键盘下沉、虚化退为后景。
  • 成品字形方案二选一，由视觉稿锁定 TBD：① 键帽本体在空间中排布构成字形；② 键帽排列为阵列、其上方浮现立体字符。两种方案下 banner 式“透光悬浮键帽”质感均须保留。
  • HERO 常驻：成品做缓慢呼吸/悬浮，镜头极缓环绕；桌面端鼠标按住拖拽环绕、滚轮缩放（方位角与俯仰、缩放距离均有上下限，不允许翻到键盘底面以下 假设·待确认）；移动端单指拖拽环绕、双指缩放；提供“复位视角”按钮（双击成品同效 P1）。
  • 文案层：主标题“TRAE 1024 程序员节快乐” TBD 文案定稿、副标题 To The Real AI Engineer（出自 banner 事实）。
  • 转化区常驻：主按钮“下载 TRAE”、次链接“官方中文社区”，均新窗口打开，URL TBD；另设“重播”与声音开关。
  • 重播时保留当前风格回到 OPENING，让访客能用喜欢的画风重看 产品判断。
结果/状态
页面停留在 HERO 直到访客点击外链离开或主动重播；无自动结束。
异常/边界
ASSEMBLING 演出期间锁定视角拖拽（点击不产生镜头位移），但风格切换可用；外链点击必须立即响应，不被动画拦截。
FR-05五风格实时切换系统（核心）P0
触发
OPENING 起全程可用：点击切换器分段/箭头、对应快捷键（6.2）；触屏为卡片分段点选。
通用规则
  • 五风格是同一场景的视觉重映射：切换时三维几何、演出进度、镜头位置不改变，仅画面渲染风格在 0.6–1.0s 内过渡 假设·待确认；禁止整页白闪或重载。
  • 风格化仅作用于三维画布；导航、按钮、切换卡等 HTML 控件层保持恒常深色品牌 UI，不被滤镜改变，以保证文案可读性与开发收敛 产品判断。水墨风下的纸色卡片皮肤列为 P1 待评审。
  • 默认风格：像素风（S1）开场——像素与程序员节符号最贴合 产品判断，待品牌确认；是否增加第 6 个“TRAE 写实原版”见第 7 节。
  • 切换器固定在左下角，构成复刻素材卡：胶囊 STYLE 0X / 05、风格中文名 + 英文名、一行风格说明、五段进度指示器（当前段为琥珀色、已过为暗灰、未到为深底线）、左右切换按钮；卡片不遮挡主角键帽与 HERO 字形，窄屏自适应为底部通栏。
  • 过渡中连续操作：以最后一次选择为准，打断当前过渡转向新目标；不可出现多个风格叠加的错乱帧。
  • 资源未就绪的风格：分段置灰不可点；就绪后自动恢复可点，无需刷新。

低多边形
Low poly		 所有曲面被三角折面替代，折面内单一明暗、棱线硬朗；键帽如切面宝石，背光在折面间呈块状跳变；环境为黄昏暖金调（参考图气质）。

卡通渲染
Toon shading		 明暗约三档阶调、阴影区偏冷色；所有物体带手绘墨线轮廓（描边随深度/法线变化）；赛璐璐式干净色块，键帽边缘轮廓清晰。
素材卡技法：N·L 三档阶梯化 + 冷阴影偏移 + G-buffer 深度/法线描边		 品牌绿饱和明快、保持官方绿色相；紫键轮廓清楚。
S4
油画
Oil painting		 细节被涂抹为大块笔触、大轮廓保留而内部柔化；全画面叠加画布编织纹理；整体暖调。
素材卡技法：Kuwahara 保边滤波（四象限最小方差均值）+ 画布纹理，参考参数 radius 11px / 196 samples		 绿色背光与键面字符允许笔触化但必须可辨认，不得糊成一团；TRAE1024 字形可识别为下限。

水墨
Ink wash		 宣纸米白底色；墨色由明暗与深度决定浓淡（墨分五色）；物体边缘有干笔“飞白”噪声；朱砂红仅用于点睛（红日/印章元素）。

FR-06声音P0
触发
遵循浏览器自动播放策略：页面发生首次任意用户交互（点击/按键/触摸）后启用声音；在此之前视觉演出照常无声进行。
处理规则
  • 逐键音：8 次机械轴敲击声，在两三个相近样本/音高间轻微变化避免单调；与键帽下沉瞬间对齐。
  • ASSEMBLING：一次汇聚/成型音效；风格切换：轻确认音（可省略）待音效设计。
  • HERO 阶段 P0 无循环配乐（氛围乐为 P1）。
  • 控件：喇叭开/关按钮，快捷键 M；用户静音选择写入 localStorage，回访保持静音。
结果/状态
声音开 ↔ 关两态；首次交互前按钮以“静音/待交互”态呈现且不误导。
异常/边界
音频资源加载失败不影响视觉演出，控件恒为不可操作的静音态；切到后台标签页时声音挂起，回前台不补放已错过的音。音效素材版权 TBD。
FR-07响应式、性能分级与降级P0
触发
页面加载时的设备能力探测，以及运行中的帧率表现。
处理规则
  • 断点：≥1024px 桌面完整布局；<1024px 平板/移动使用竖向重构图、底部风格选择条、HERO 文案与主 CTA 不遮挡字形。
  • 性能分级（静默，不打扰访客）：高档全分辨率 + 五风格完整效果；中档降低后期采样分辨率与粒子密度；低档关闭/简化重计算风格效果（油画、水墨类），像素风以低分辨率方式天然保留，其余风格以降质版呈现。五个选项任何档位下都不消失。
  • WebGL 不可用：进入 FATAL FALLBACK——展示成型态主视觉（预渲染图，由设计提供 TBD，建议含至少像素/水墨两版）、两个转化出口、一句“建议使用最新版桌面浏览器完整体验”，以及“重试”入口。
  • 减弱动态效果（prefers-reduced-motion）：跳过 OPENING 与 ASSEMBLING 运动，加载后直接呈现 HERO；风格切换用 ≤0.3s 淡入；键帽呼吸与镜头缓动关闭。
  • 受支持浏览器：最新两个大版本的 Chrome / Edge / Safari / Firefox 假设·待确认；不支持 IE。
异常/边界
运行中持续低帧率可动态再降一档（不回调升档，避免反复跳变）；窗口尺寸/横竖屏切换时场景自适应，演出状态与当前风格不重置。
FR-08页面框架与品牌出口P0
触发
全阶段常驻。
处理规则
  • 顶部：左上 TRAE 字标（点击新窗口打开官网首页，URL TBD）；右上“下载 TRAE”主按钮（同 HERO 出口）；活动日期以代码装饰样式呈现 >>date{10.19 - 10.24}（出自 banner 事实）。
  • HERO 转化区：主按钮“下载 TRAE”、次链接“官方中文社区”（Banner 已有“官方中文社区”入口 事实）；全部外链新窗口打开。
  • 控件：风格切换卡（FR-05）、重播、声音开关；移动端收纳规则：声音/重播为图标按钮，风格卡为底部通栏。
  • 页脚：版权与法务链接清单（隐私政策/用户协议等）TBD 法务提供；不设多页站点导航。
异常/边界
外链 URL 未配置前以禁用态（按钮置灰、hover 提示“即将上线”）上线，不得出现死链。

6.3 边界情况汇总

输入类

  • 快速连按/多键同按：仅接受当前目标键一次，不跳键、不重入。
  • 触屏与物理输入混用：共用同一键位指针，互不冲突。
  • 输入法开启时字母键可能不产生事件：不影响自动演出，触屏入口始终可用。

视图类

  • 窗口缩放 / 旋转屏：场景自适应，状态与风格保持。
  • HERO 拖拽越界：方位/俯仰/缩放均钳制在限定范围。
  • 小屏：风格卡不得与主 CTA、字形重叠。

生命周期

  • 后台切回：从冻结处继续，不补动画、不补声音。
  • 加载中刷新：重新 LOADING。
  • 外链均 target 新窗口，原页面状态保留便于返回。

可访问性

  • 风格卡使用 tablist 语义，焦点可见，支持 Tab + 方向键操作。
  • 颜色不作为唯一状态信号：分段附 01–05 编号，声音有图标两态。
  • 所有声音事件均有等价视觉反馈；支持 prefers-reduced-motion。
  • 正文与按钮对比度遵循 WCAG AA 假设·待确认。
